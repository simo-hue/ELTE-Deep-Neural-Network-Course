README - Deep Network Development, Coding test example pack (Autumn 2026)

The two example Coding tests in this package were designed for a test duration of 180 minutes. During the test, you will need to work on the desktop computers in the university's computer labs using Windows. There will be no internet access. You will have access to the following content during the test:

  • The contents of this package. In the dnd26au_example_coding_test_pack/course_materials folder, you can access the slides and notebooks which were shared on the main course page of Moodle. Materials handed out by practice leaders will not be accessible.
  • Documentation pages for Python and relevant packages can be accessed via the links provided in the dnd26au_example_coding_test_pack/docs.html. (Version updates may occur.) These pages are hosted on our server. The built-in search feature works for most of them. Make sure you open the documentation in your browser and not inside JupyterLab, as this may break the search feature.
  • Your own Homework submission will also be available through a separate URL. Please note that we remove any significant amount of irrelevant code and all cell outputs from your submission before making it available.
  • JupyterLab is the only IDE guaranteed to be available to you during the Coding test. While other IDEs may be available, we cannot guarantee that they will work properly.

Launch JupyterLab from a location that it can access the extracted files! (For example, if you extracted the files to your user’s Documents folder, you can launch the software from the command line, from the Documents folder, or from one of its parent folders using the jupyter lab command.) Make sure to not close the terminal window as this will break JupyterLab.

In the JupyterLab interface, on the left side, locate one of the example Coding test notebook from the contents of the extracted files: dnd26au_example_coding_test_pack/dndmsc26spring_zh1a.ipynb or dnd26au_example_coding_test_pack/dndmsc26spring_zh1b.ipynb and double-click it! You can edit and run the notebook.

If you encounter an error when running a code cell, you should first establish whether the error was produced by your code or by the automatic tester script. If the error comes from the tester script, you can check the error message (stack trace) to see which line of code in the tester script produced the error. You can open the relevant tester script file (located next to the Coding test notebooks: dndmsc26spring_zh1a_tester.py or dndmsc26spring_zh1b_tester.py), find the corresponding line of code and check the failed test case/assertion.

Good luck!
